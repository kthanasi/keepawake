Installing takes a minute

  1. Download the disk image

    Grab the .dmg from the latest release.

  2. Drag it into Applications

    Open the downloaded file and drop KeepAwake into the Applications folder beside it.

  3. Right‑click it, then choose Open

    Just for the very first launch. After that it opens like any other app — look for the ☕️ cup at the top‑right of your screen.

Why the right‑click? macOS warns about apps that haven't gone through Apple's paid notarization programme, which this one hasn't. Right‑click → Open is macOS's normal way of saying "I trust this one," and you only do it once. Every update afterwards is cryptographically signed and verified before it installs.

Questions

Does it stop my screen from locking?

It keeps the display from sleeping, and the lock that normally follows sleep won't happen either. It doesn't touch your password or Screen Time settings — lock the screen yourself any time with Control‑Command‑Q.

Will it keep my Mac awake with the lid closed?

No. Closing the lid always puts the Mac to sleep, and no app can override that.

Does it drain the battery?

The app itself uses no measurable power — it holds a flag the kernel owns, with nothing running in the background. Your screen staying lit does use power, which is rather the point, so a timed session is the battery‑friendly way to use it.

Does it send my data anywhere?

No. There's no account, no analytics, and no tracking. The only network request it ever makes is asking GitHub whether a newer version exists.

How do I uninstall it?

Quit it from its menu and drag KeepAwake from Applications to the Trash. To clear its settings too, run defaults delete com.kthanasi.KeepAwake in Terminal.

Can I read the source?

All of it — the entire app is a single Swift file. It's on GitHub under the MIT licence, so you're free to build it yourself, change it, or ship your own version.
